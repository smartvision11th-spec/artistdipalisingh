# CHANGELOG

This file records meaningful changes made to the artistdipalisingh project.

The changelog should focus on:

* project milestones
* architectural changes
* major design changes
* important feature additions
* important fixes
* backend changes
* production-related changes

Small typo fixes and insignificant formatting changes do not need to be recorded.

# Changelog Principle

The changelog should document meaningful evolution of the project.

It should answer:

> What changed, when did it change, and why?

It should not become a diary of every button that was moved two pixels to the left.
